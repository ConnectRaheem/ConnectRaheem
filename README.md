I design and ship end-to-end ML and LLM-powered applications — from fine-tuned deep learning models to multi-tool conversational agents. My focus is turning research-grade models into systems that actually run in production: proper APIs, memory/state handling, structured outputs, and clean deployment.

- 🧠 Machine Learning & Deep Learning (classification, NLP fine-tuning, model evaluation)

- 💬 AI chatbot development — customer support agents, PDF/document Q&A bots, domain-specific assistants
- 🔤 Text classification & sentiment analysis (transformer fine-tuning)
- 🧰 End-to-end NLP tooling: summarization, NER, keyword extraction
- 📊 Data engineering pipelines to support ML workflows
